# V36 Figma Design Basics Pass

This pass translates the Figma Design Basics library into a practical portfolio system rather than adding more decoration.

## What changed

- Reframed the homepage around the recruiter's core tasks: understand who Neha is, scan experience, inspect projects, open the resume.
- Introduced semantic design tokens for color, spacing, radii, content width, reading width, focus, and motion.
- Standardized the spacing rhythm around an 8 point scale.
- Tightened the typography hierarchy and limited long-form reading width.
- Preserved the restrained cream and aura visual identity while reducing reliance on decorative surfaces.
- Kept project imagery as the dominant project-card element and made project cards real navigation links.
- Added consistent default, hover, active, focus, disabled, and selected interaction behavior.
- Increased navigation and key-action hit areas to at least 44px where practical.
- Added stronger keyboard focus treatment, reduced-motion behavior, increased-contrast support, and forced-color fallbacks.
- Improved mobile navigation so Experience, Projects, and Resume remain directly available while Fun builds becomes secondary.
- Standardized project media, case-study media, and About imagery around a smaller shared radius system.
- Made the About disclosure control behave more clearly when opened.
- Preserved the company-aware Experience aura behavior and case-study aura palettes.

## Design rules carried forward

- One visual priority per section.
- Use proximity before borders or cards to show relationships.
- Use contrast to create hierarchy, not decoration.
- Reveal detail progressively instead of showing everything at once.
- Keep familiar interaction patterns familiar.
- Use the same spacing, type, and interaction system everywhere.
- Treat responsive behavior and accessibility as constraints from the start.
- Use real copy when judging layout and line length.
- Make interactive targets easy to acquire and visibly responsive.
- Prefer clarity over novelty when the two conflict.
