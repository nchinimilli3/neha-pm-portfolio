# Neha Chinimilli Portfolio

React + Vite portfolio built for GitHub Pages.

## Local preview

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

GitHub Pages base path is configured for `/neha-pm-portfolio/`.

## Interactive demos

The Collaborative Scheduling Platform sandbox is a browser-only recreation based on the original `homework/Final/` Flask/MySQL/Socket.IO project. The Synchronized Group Chat sandbox is based on the original `homework/Homework-3/` Socket.IO chat. Backend behaviors are simulated locally so both demos can run on GitHub Pages.
