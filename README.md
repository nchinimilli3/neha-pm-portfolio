# Neha PM Portfolio — V11 Latest

This is the consolidated React + TypeScript portfolio source.

## V11 changes
- Visual-first project card homepage; details move behind the click.
- Scheduler is the featured interactive project and explicitly shows the When2Meet core versus the added coordination layer.
- Case-study pages open with a large project visual and evidence/metrics rather than long homepage copy.
- Experience is a three-card logo section with concise role/scope descriptions.
