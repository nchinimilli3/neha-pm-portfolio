# Neha Chinimilli — Product Portfolio

React + Vite portfolio prepared for GitHub Pages.

## Upload to GitHub
Upload the **contents of this folder** to the root of `nchinimilli3/neha-pm-portfolio` (not the outer folder itself).

Keep your existing `.github/workflows/deploy.yml` if it is already working.

## Resume
The navigation expects `public/resume.pdf`. Add your current resume there before deploying.

## Local preview
```bash
npm install
npm run dev
```

## GitHub Pages path
`vite.config.js` is already configured with `base: '/neha-pm-portfolio/'`.
