# Neha Chinimilli Portfolio — V7 LATEST

This is the consolidated portfolio package. Use this version instead of V5, V6, V6.1, or V6.2.

## Included from the design iterations

- Cream editorial base with a dispersed, slowly animated aurora field across the full page.
- Large, readable typography and factual, concise copy.
- No promotional eyebrow labels or sales-y taglines.
- Main project layout inspired by large editorial case-study rows.
- Customer Value Framework and FinSimple use real presentation screenshots.
- Estée Lauder uses relevant screens from the original Double Wear project.
- Individual case-study views for all five main projects.
- Verified metrics only; unsupported metrics are intentionally omitted.
- Collaborative Scheduling sandbox based on the original `homework/Final/` project and its When2Meet extensions.
- Scheduler includes Available / Maybe / Unavailable, quick-fill presets, My Availability / Group Heatmap, best-time logic, participant status, venue voting, notes, event chat, sharing, and calendar export behavior.
- Synchronized Group Chat sandbox mirrors the original real-time/iMessage-style behavior: current-user vs other-user bubbles, join/leave events, typing state, and tapbacks/reactions.
- Compact “More technical work” grid for CSE 335 Team Game, Stable Fluids, and Ray Tracer.
- Compact Experience and About sections.
- React + TypeScript + Vite project structure.
- GitHub Pages workflow included at `.github/workflows/deploy.yml`.
