# V25 — Commute iPhone demo

- Rebuilt Commute sandbox as a contained iPhone-app experience rather than a control panel around a static phone.
- Added first-launch onboarding: morning routine, simulated Apple Health walking permission, simulated Calendar connection, and first commute setup.
- User-entered origin, destination, arrival time, buffer, routine and Health state persist through the demo and affect wake/leave calculations.
- Added app-level Today, Plan and More navigation with familiar iOS interaction patterns.
- Added in-phone route reasoning, sleep-longer choices, commute-condition controls, saved-commute editing and a restart-demo path.
- Health and Calendar permission flows are explicitly labeled as portfolio simulations; no real private data is accessed by the browser sandbox.
- Reduced external sandbox chrome and explanatory controls so the recruiter interacts with the product itself.

- Added subtle per-source freshness indicators for BART, AC Transit NL, and Bay Bridge traffic.
- Live/stale state now appears inside Today, Why, and Conditions views instead of as a marketing badge.
